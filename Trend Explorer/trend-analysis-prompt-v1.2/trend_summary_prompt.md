# 趋势摘要生成 Prompt

请基于最近一段时间的榜单、标签、作品和平台热度数据，生成“全网风向标”趋势摘要。摘要要服务推荐系统、运营分析和前端趋势大屏。

时间范围：

{time_range}

趋势作品与榜单数据：

{trend_items}

平台统计与对比数据：

{platform_stats}

摘要关注点：

{summary_focus}

分析任务：

- 总结当前全网网络小说市场最明显的热门题材和上升元素。
- 如果数据包含历史月票榜，请比较不同月份的 `listType`，提炼哪些题材、标签或作品元素从 1 月到 4 月持续上升、阶段性爆发或热度回落。
- 判断不同平台的榜单偏好差异，例如玄幻强势、都市畅销、悬疑讨论度提升、女频情绪价值增强等。
- 提炼上升最快作品的共同特征，例如短周期强刺激、设定新鲜、群像冲突、轻量金手指、强人设反差。
- 识别可能衰退或热度放缓的元素，但不要在证据不足时武断下结论。
- 输出内容要能直接被 API 或前端大屏使用：短、准、结构化。

只输出合法 JSON，不要输出 Markdown 或解释文字。字段必须完全使用以下结构：

{

  "genre": "",
  "hot_elements": [],
  "reader_emotion_value": [],
  "trend_reason": "",
  "evolution_relation": {
    "from": null,
    "to": null,
    "logic": ""
  },
  "confidence": 0.0
}
